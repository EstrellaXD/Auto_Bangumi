# 多下载器

从 4.0 开始，AB 可以同时连接多个下载器，例如本机的 qBittorrent 和 NAS 上的另一个 qBittorrent 或 aria2。每个下载器是一个**实例**，有自己的 id、类型、地址、账号与下载地址。其中一个实例是**默认实例**。

只有一个下载器时，一切与 3.x 相同，界面中也不显示下载器选择。

## 管理下载器

打开 **设置 → 下载设置**。顶部列出所有下载器实例，默认实例带「默认」标记。

- **编辑**：点击一个实例，在下方修改它的类型、地址、用户名、密码、下载地址与 SSL。
- **添加**：输入新下载器 id，点击 **添加**。id 只能包含字母、数字、`_` 与 `-`。
- **设为默认**：把一个实例设为默认实例。
- **删除**：删除一个实例。默认实例不能删除。

下载器类型可以选 qBittorrent、aria2，或插件提供的下载器。修改后点击底部的 **保存并重启**。各选项与 `config.json` 格式见 [下载器设置](../config/downloader.md)。

## 为规则选择下载器

有多个下载器时，以下位置出现 **下载器** 选项。留空表示跟随默认实例。

- **添加 RSS**：为订阅选择下载器。订阅与收集都使用它。
- **番剧编辑弹窗 → 高级设置**：为单个规则选择下载器。

新种子按以下顺序选择下载器：

1. 规则选择的下载器。
2. 规则未选择时，用订阅选择的下载器。
3. 两者都未选择时，用默认实例。

由订阅自动新建的规则，会继承订阅选择的下载器。从顶栏搜索添加的番剧使用默认实例，之后可以在高级设置中修改。

种子保存在所选实例的下载地址下。

## 种子记录在哪个下载器

AB 记录每个种子被添加到的下载器。之后的重命名、删除都在该下载器上进行。

- **下载器页**：有多个下载器时，列表多出「下载器」列。暂停、恢复、删除等批量操作会发到每个种子所在的下载器。
- **种子列表**：规则与未匹配种子的列表标出每个已下载种子所在的下载器。

## 修改之后已有的种子

| 操作 | 已有的种子 | 新种子 |
| --- | --- | --- |
| 规则改用另一个下载器 | 留在原下载器的原位置，不迁移。AB 继续在原下载器上整理它们 | 进入新下载器的下载地址 |
| 更改默认实例 | 不变 | 未选择下载器的规则与订阅改用新的默认实例 |
| 删除一个下载器 | 不受影响，仍留在该下载器中。AB 不再连接它，也不再整理其中的种子 | 选择它的规则与订阅改用默认实例 |
| 删除规则并删除文件 | AB 在记录的每个下载器上删除该规则的种子 | — |

## 下载器连接不上时

AB 逐个下载器运行重命名。某个下载器连不上时，AB 跳过它，其它下载器照常处理。该下载器从可用变为不可用时，AB 发送一次「下载器连接异常」通知；恢复后再次不可用时会再次通知。

添加种子时目标下载器不可用：该种子不入库，下一轮 RSS 刷新时重试。

## 从 3.x 升级

升级到 4.0 后第一次启动时，AB 把 3.x 的下载器设置迁移为 id 为 `default` 的实例，并设为默认实例。已有的种子都记录在 `default` 中；已有的规则与订阅未选择下载器，跟随默认实例。原配置文件备份为 `config.json.v3.bak`。
