# ファイルリネーム

ABには4つのリネーム方法があります：`pn`、`advance`、`template`、`none`。**設定 → アニメ管理設定 → リネーム方式** で選択します。既定は `pn` です。

4.0 から、リネーム方法はプラグインが提供します：

- `none` は AB に内蔵されており、常に使用できます。
- `pn`、`advance`、`template` は内蔵プラグイン `rename` が提供します。このプラグインは既定で有効です。
- 他のプラグインもリネーム方法を追加できます。そのプラグインを有効にすると、ドロップダウンに表示されます。

**設定 → プラグイン** で `rename` プラグインを無効にすると、すべての番組が `none` として扱われます。プラグインが 5 回連続でエラーになり AB に自動で無効化された場合も同じです。選択した方法が使用できないとき、AB はログを 1 回だけ記録し、`none` として扱います。

### pn

`pure name`の略です。ファイル名から解析したタイトルでリネームします。

例：
```
[Lilith-Raws] 86 - Eighty Six - 01 [Baha][WEB-DL][1080p][AVC AAC][CHT][MKV].mkv
>>
86 - Eighty Six S01E01.mkv
```

### advance

高度なリネーム。番組フォルダ名でリネームします。

```
/downloads/Bangumi/86 - Eighty Six(2023)/Season 1/[Lilith-Raws] 86 - Eighty Six - 01 [Baha][WEB-DL][1080p][AVC AAC][CHT][MKV].mkv
>>
86 - Eighty Six(2023) S01E01.mkv
```

`pn` と `advance` の結果は 3.x とまったく同じです。劇場版には `SxxExx` を付けません。字幕ファイルは拡張子の前に言語が付きます（例：`.zh.ass`）。

### template

独自のテンプレートでリネームします。テンプレートは **設定 → プラグイン** の `rename` プラグインの `template` オプションに入力します。

### none

リネームなし。ファイルはそのまま残されます。

## テンプレートリネーム

::: v-pre
既定のテンプレートは次のとおりです。通常のエピソードでは結果は `pn` と同じです。劇場版では `pn` は `SxxExx` を付けませんが、既定のテンプレートは付けます：

```
{{ title }} S{{ season|pad(2) }}E{{ episode|pad(2) }}
```

テンプレートは [Jinja2](https://jinja.palletsprojects.com/) 構文を使い、サンドボックス内でレンダリングされます。使用できる変数：

| 変数 | 意味 | 例 |
| --- | --- | --- |
| `title` | ファイル名から解析したタイトル | `葬送のフリーレン` |
| `bangumi_name` | 番組フォルダ名 | `葬送のフリーレン (2023)` |
| `season` | シーズン。Season フォルダから取得し、シーズンオフセットを含みます | `1` |
| `episode` | 話数。エピソードオフセットを含みます。半話は小数を保持します | `5`、`12.5` |
| `episode_type` | `episode`、`movie`、`special` のいずれか | `episode` |
| `group` | 字幕組。空の場合があります | `ANi` |
| `kind` | `media`（本編）または `subtitle`（字幕） | `media` |
| `language` | 字幕の言語。本編では空です | `zh` |

フィルター `pad(n)` は数値の整数部分を n 桁までゼロ埋めします（n を省略すると 2）。小数部分は保持します：`{{ episode|pad(3) }}` は `005`、`{{ 12.5|pad(2) }}` は `12.5` になります。

- テンプレートはファイル名の本体だけを生成します。拡張子は AB が付けます。字幕には拡張子の前に `.言語` を付けます（例：`.zh.ass`）。
- テンプレートは劇場版を特別に扱いません。区別するには `episode_type` を使います。例：`{% if episode_type == "movie" %}{{ bangumi_name }}{% else %}…{% endif %}`。保存時の検証は通常のエピソードのサンプルを 1 つだけレンダリングします。サンプルが通らない分岐のエラーは、リネーム時に初めて現れます。

例：`[{{ group }}] {{ bangumi_name }} - {{ episode|pad(2) }}` → `[ANi] 葬送のフリーレン (2023) - 05.mkv`
:::

### テンプレートのエラー

- **保存時**：AB はサンプルファイルでテンプレートを 1 回レンダリングします。構文エラー、存在しない変数、不正な結果のときは保存されず、元のテンプレートが残ります。
- **リネーム時**：ファイルのレンダリングに失敗した、結果が空、または `/`、`\`、制御文字を含む場合、そのファイルは**元の名前のまま**になり、AB は「ファイル名を変更しませんでした」通知を送ります（WebUI では「文件未重命名」/「Files kept their names」）。同じトレントと同じ理由の通知は、AB の実行中に 1 回だけです。そのトレントには `ab:renamed` タグが付かないので、テンプレートを修正すると次の回で自動的に再試行されます。**`pn` にフォールバックしません。**
- **`config.json` を手で編集した場合**：保存済みのテンプレートが不正だと、`rename` プラグイン全体が読み込めません。`pn`、`advance`、`template` がすべて使用できなくなり、すべての番組が `none` として扱われます。プラグインのカードにエラー理由が表示されます。

::: warning
リネーム方式の変更（テンプレートの変更を含む）は、変更後に整理されるトレントにだけ適用されます。整理済み（`ab:renamed` タグ付き）のトレントは再リネームされません。
:::

`config.json` の設定場所は [アニメ管理設定](../config/manager.md) を参照してください。

## コレクションのリネーム

ABはコレクションのリネームをサポートしています。コレクションのリネームには以下が必要です：
- エピソードがコレクションの第1レベルディレクトリにある
- ファイル名からエピソード番号を解析できる

ABはまた、第1レベルディレクトリ内の字幕ファイルもリネームできます。

リネーム後、エピソードとディレクトリは`Season`フォルダに配置されます。

リネームされたコレクションは`BangumiCollection`の下に移動され、カテゴリ分けされます。

## エピソードオフセット

v3.2以降、ABはリネーム用のエピソードオフセットをサポートしています。これは以下の場合に便利です：
- RSSが期待と異なるエピソード番号を表示（例：S2E01がS1E29であるべき）
- 放送ギャップによるアニメの「仮想シーズン」がある

番組にオフセットが設定されている場合、ABはリネーム中に自動的に適用します：

```
元：S02E01.mkv
オフセット適用後（シーズン：-1、エピソード：+28）：S01E29.mkv
```

オフセットを設定するには：
1. アニメのポスターをクリック
2. 詳細設定を開く
3. シーズンオフセットおよび/またはエピソードオフセットの値を設定
4. または「自動検出」を使用してABに正しいオフセットを提案させる

自動検出の詳細については、[番組管理](/ja/feature/bangumi#エピソードオフセットの自動検出)を参照してください。

## リネームの後

リネームが終わると、AB は「整理完了」イベントを発行します。リネーム方式が `none` のときも発行します。内蔵プラグインはその後もファイルを処理できます：

- [メディアライブラリへのハードリンク](./hardlink.md)：整理済みのファイルを別のフォルダにリンクします。ダウンロードフォルダのトレントはシードを続けます。
- `media-server-refresh`：Jellyfin、Emby、Plex にライブラリの更新を要求します。[アニメ管理設定](../config/manager.md) を参照してください。
